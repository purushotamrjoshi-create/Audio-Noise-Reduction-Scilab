\# 🎧 Audio Noise Reduction System Using Digital Signal Processing



\## 📌 Overview



This project implements a basic Audio Noise Reduction System using Digital Signal Processing (DSP) techniques in Scilab.



The system starts with a clean speech audio signal, adds artificial random noise, and then applies a Moving Average Filter to reduce the noise.



The project also analyzes the audio signals in both the time domain and frequency domain using Fast Fourier Transform (FFT).



\---



\## 🎯 Objectives



\- Load and analyze a WAV audio signal

\- Generate artificial noise

\- Create a noisy audio signal

\- Apply a Moving Average Filter

\- Compare clean, noisy, and filtered signals

\- Analyze frequency spectra using FFT

\- Calculate Signal-to-Noise Ratio (SNR)

\- Save the processed audio signals as WAV files
